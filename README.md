# li-books-studio

Chat-first Next.js UI for li-books (evolved from `documenting-receipts`).

## Role

- Primary home = chat per bookkeeping book
- Drag-drop receipt upload in chat
- Clarification question cards + inbox badge
- Playwright e2e from WP-140

## Dev

```bash
npm install
npm test
```

Full Next.js scaffold lands in WP-140.
